PM2 — Password Cracking with Networkwalks Tools

Module Overview

This module focused on recovering the password of a protected PDF using the **Networkwalks Hash Calculator** and **Networkwalks Password Cracker**.

The exercise was performed against the PDF files supplied as part of the Networkwalks Academy Week 3 training lab.

Tools Used

- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Windows
- WPS Office / PDF viewer

Practical Workflow

1. Uploaded a protected PDF to the Networkwalks Hash Calculator.
2. Extracted the PDF password hash in `$pdf$` format.
3. Copied the complete hash.
4. Opened the Networkwalks Password Cracker.
5. Submitted the extracted hash using the built-in dictionary.
6. Started the password-cracking process.
7. Recovered the PDF password.
8. Used the recovered password to unlock and verify the protected PDF.

Practical Result

The Networkwalks Password Cracker successfully recovered the password during the authorized training exercise.

The recovered password and raw PDF hash are intentionally not published in this repository.

Additional Practice

An additional supplied training PDF was also processed using the same Networkwalks workflow to reinforce the hash-extraction and dictionary-attack process.

Skills Practiced

- PDF password hash extraction
- Dictionary-based password cracking
- Hash analysis
- Networkwalks security tools
- Password verification
- Cybersecurity laboratory documentation

Scope

All activities were performed against the provided Networkwalks training PDF files within the authorized internship laboratory environment.

No third-party systems, accounts, or unauthorized files were targeted.
