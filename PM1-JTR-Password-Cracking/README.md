PM1 — Password Cracking with John the Ripper

Module Overview

This module focused on recovering the password of a protected PDF using **John the Ripper (JTR)** and the **Johnny graphical interface**.

The exercise was performed against the PDF supplied as part of the Networkwalks Academy Week 3 training lab.

Tools Used

- John the Ripper 1.9.0-jumbo-1
- Johnny GUI
- PDF hash extraction tool
- Windows

Practical Workflow

1. Downloaded and configured John the Ripper.
2. Installed and configured Johnny GUI.
3. Obtained the PDF password hash from the supplied protected PDF.
4. Saved the extracted hash in `hash1.txt`.
5. Loaded the hash into Johnny.
6. Started a password-cracking attack.
7. Recovered the PDF password.
8. Verified the recovered password by opening the protected PDF.

Result

The password was successfully recovered as part of the authorized training exercise.

The recovered password and raw hash are intentionally not published in this repository.

Skills Practiced

- Password hash extraction
- PDF password analysis
- John the Ripper
- Johnny GUI
- Dictionary-based password recovery
- Password verification

No third-party systems or unauthorized files were targeted.
